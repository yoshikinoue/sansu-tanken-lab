# 算数探検ラボ（Sansu Tanken Lab）

小学4年生向けの四則演算ステップアップ学習 Web アプリケーションです。  
「自分で間違いに気づいて直せた！（自己是正感）」「わかる・できる！」という成功体験を積み重ねながら、毎日楽しく続けられるように設計されています。

---

## 主な特徴（6つのコア設計方針）

1. **ハイブリッド・ステップガイド方式（入力＆途中式サポート）**
   - 通常時は「手書き計算メモパッド（方眼・筆算ガイド付き）＋大型テンキー」でテンポよく解答できます。
   - 不正解時や難所（2桁のわり算・四則混合など）では「ステップごとの穴埋めガイド」が開き、途中の思考プロセスを1ステップずつ確認しながら自力で正解へたどり着けます。
2. **「バツ（×）」を出さない探検・ラボ風トーン**
   - 不正解時に「×（バツ）」は一切表示せず、「おしい！もう一歩！」「ヒントを発見！」といった前向きなフィードバックで挑戦を促します。
3. **参加型1分ミニ授業（図解＋2択クイズ＋音声読み上げ）**
   - 各ステージ冒頭に3ステップの図解カードと2択クイズによるミニ授業を搭載。Web Speech API による日本語音声読み上げにも対応しています。
4. **挫折しない分量とアダプティブ難易度（1セット5問）**
   - 1ステージ5問（約3〜5分）の短時間集中設計です。1問目の基礎ウォームアップから始まり、正誤履歴に応じて難易度を動的に調整します。
5. **パワーアップ宝箱 ＆ 保護者応援ボード**
   - **パワーアップ宝箱**: 間違えた問題をストックし、数字違いの類題を自力で2回連続クリアすると「完全マスター！」になります。
   - **保護者応援ボード**: 4桁PIN認証（初期値 `1234`）、全9ワールド別のレーダーチャート、じぶん修正回数カウント、応援スタンプ送信機能を備えています。
6. **安心の3重ハイブリッド保存**
   - ① ブラウザ即時保存（`localStorage`）
   - ② サーバー側ファイル自動同期（`/api/progress` ⇔ `data/progress.json`、および自動バックアップ）
   - ③ JSONバックアップの書き出し／読み込み ＆ 8文字引き継ぎコード（`LAB-XXXX-XXXX`、48時間有効）

## 学習対象範囲

本アプリは、小学4年生の算数のうち「計算」の領域に特化した学習アプリです。**学校の授業の全範囲をカバーするものではありません。**

### 対象とする内容

- 小学4年生の計算領域のうち、整数の四則計算
  - たし算・ひき算の筆算（3桁・4桁、くり上がり・くり下がり）
  - かけ算の筆算（2桁・3桁 × 1桁、2桁 × 2桁）
  - わり算の筆算（あまりのあるわり算、2桁・3桁 ÷ 1桁、何十でわる計算、2桁 ÷ 2桁の見当づけと仮の商の修正）
  - 計算の順序と工夫（カッコのある計算、四則混合、分配・結合法則）
  - 虫食い算・逆算（□の式）
- あわせて、小学3年生で学ぶ計算の復習要素を含みます

### 対象外の内容

以下は現時点では扱っていません。

#### 今後の課題としてイシューで管理している内容

- 小数（[#16](https://github.com/yoshikinoue/sansu-tanken-lab/issues/16)）
- 分数（[#17](https://github.com/yoshikinoue/sansu-tanken-lab/issues/17)）
- 大きな数と概数（[#18](https://github.com/yoshikinoue/sansu-tanken-lab/issues/18)）
- 文章題（[#19](https://github.com/yoshikinoue/sansu-tanken-lab/issues/19)）

#### 対象外と決定した内容

- 図形（角・平行と垂直・四角形・直方体）、面積、折れ線グラフなどのデータの活用

本アプリは計算専用と位置づけており、上記は [#22](https://github.com/yoshikinoue/sansu-tanken-lab/issues/22) で対象外と決定しました。実装予定はありません。

## 技術スタック・動作環境

- **ランタイム**: Node.js v24 以上推奨（外部ランタイム依存ゼロ / `dependencies: {}`）
- **フロントエンド**: Vanilla ES Modules (`src/`) + CSSデザインシステム (`src/styles/`) + PWA (`manifest.json`)
- **開発ツール**: Vite (`devDependencies`)
- **テスト**: Node.js 標準テストランナー (`node:test`, `node:assert`)

---

## 起動方法

用途に合わせて4通りの方法で起動・利用できます。

### 1. Node.js サーバーで起動（推奨・サーバー同期あり）

```bash
npm start
# または
node server.js
```

起動後、ブラウザで以下にアクセスします（環境変数 `PORT` でポート変更可能、デフォルト `3000`）：
- **アプリ本編**: `http://localhost:3000/`
- **進捗 API**: `http://localhost:3000/api/progress`

### 2. Vite 開発サーバーで起動

```bash
npm install   # 初回のみ（Vite を利用する場合）
npm run dev
```

### 3. スタンドアロン HTML で起動（サーバー不要）

リポジトリ直下の [`sansu_tanken_lab.html`](./sansu_tanken_lab.html) をそのままブラウザで開きます。  
CSS および全 ES モジュールが単一ファイルにバンドルされており、`localStorage` と JSON バックアップ機能を用いて単体で動作します。

### 4. 静的ホスティング（GitHub Pages 等）

`.nojekyll` を同梱しているため、リポジトリをそのまま静的ホスティングへ公開できます。  
静的ホスティング環境ではサーバー API を使わず、`localStorage` と JSON バックアップ／読み込みモードで自動動作します。

## API エンドポイント概要（`server.js`）

| メソッド | パス | 概要 |
|---|---|---|
| `GET` | `/api/progress` | 保存されている学習進捗データ（`schemaVersion: "1.0.0"`）を取得 |
| `POST` | `/api/progress` | 学習進捗データを検証し、バックアップ付きでアトミック保存 |
| `POST` | `/api/transfer/generate` | 8文字の引き継ぎコード（`LAB-XXXX-XXXX`、48時間有効）を発行 |
| `POST` | `/api/transfer/claim` | 引き継ぎコードから学習進捗データを復元 |
